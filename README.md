# Python Tuple Programs

## 📌 Overview

This repository contains Python programs that demonstrate various **Tuple** operations. These examples help beginners understand tuple concepts and common operations in Python.

## 🎯 Objectives

* Learn Python Tuples
* Understand tuple operations
* Practice built-in tuple methods

## 🛠️ Technologies Used

* Python 3.x
* VS Code / PyCharm

## 📂 Programs Included

* Create a tuple
* Access tuple elements
* Tuple slicing
* Count occurrences of an element
* Find the index of an element
* Concatenate tuples
* Repeat tuples
* Iterate through a tuple
* Find maximum and minimum values
* Convert between list and tuple

## ▶️ How to Run

1. Install Python 3.x.
2. Open the project in VS Code or PyCharm.
3. Run the program using:

```bash
python filename.py
```
